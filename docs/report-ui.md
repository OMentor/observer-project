## 1. Краткое резюме

Дизайн-спецификация дизайнера переведена в рабочую дизайн-систему веб-клиента:
токены оформления, типографика и шрифты, набор UI-компонентов, каркас
(шапка/сайдбар), все экраны, анимации и базовая доступность.

Реализация разбита на 5 фаз (каждая — отдельный коммит):

| Фаза | Содержание | Коммит |
|------|------------|--------|
| 1 | Токены, темы, шрифты, тёмная тема по умолчанию | `22ab028` |
| 2 | UI-примитивы (кнопки, поля, карточки, модалки, тосты и т.д.) | `f40068d` |
| 3 | Каркас: шапка 64px, сворачиваемый сайдбар 280/64, поиск | `7ee01c0` |

| 5 | Анимации, стаггер списков, доступность (a11y), reduced-motion | `77a8b3a` |

Проверки каждой фазы: TypeScript — без ошибок, oxlint — 0 замечаний,
Vitest 1/1, production-сборка Vite — успешно.

## 2. Реализовано: токены оформления

Тёмная тема — **основная** (по умолчанию), светлая — включается классом `.light`
на `<html>`. Значения заданы в `web/src/styles/themes.css`, проброшены в Tailwind 4
через `@theme inline` (`web/src/index.css`).

### 2.1 Цвета

| Группа | Токены | Тёмная (основная) | Светлая |
|--------|--------|-------------------|---------|
| Фоны | `bg` / `bg-surface` / `bg-elevated` | `#1A1A1E` / `#25252B` / `#2E2E35` | `#FAF8F5` / `#FFFFFF` / `#F0EDE8` |
| Границы | `border` / `border-subtle` | `#3A3A42` / `#2E2E35` | `#E0DCD5` / `#EDEAE4` |
| Акцент | `accent` (+hover/active/muted) | `#5B5FEF` | `#4A4EE0` |
| Amber (токены доступа) | `amber` (+hover/active/muted) | `#F0A030` | `#D98A1F` |
| Успех | `success` (+muted) | `#34C77B` | `#2BA865` |
| Опасность/конфликт | `danger` (+hover/active/muted) | `#E05C4A` | `#C94A38` |
| Текст | `text-primary` / `text-secondary` / `text-muted` / `text-inverse` | `#F5F3EF` / `#A8A29E` / `#7D7872` / `#1A1A1E` | `#1A1A1E` / `#6B6660` / `#8A837C` / `#FAF8F5` |
| На акцентной подложке | `on-accent` | `#FFFFFF` | `#FFFFFF` |

`text-muted` затемнён для тёмной и светлой тем; `on-accent` — белый текст для
кнопок/бейджей на акцентном фоне (обе темы). Значения исправлены по результатам
аудита контраста (раздел 10).

Прозрачные «muted»-варианты акцентов реализованы как `rgba(...)` (подложки бейджей,
чипов, конфликтов).

> Примечание о совместимости: сохранены устаревшие имена токенов
> (`surface`→`bg-surface`, `text`→`text-primary`, `muted`→`text-secondary`,
> `conflict`→`danger`, `accent-2`→`amber`), чтобы не переписывать всю разметку
> разом. Это технический компромисс (см. раздел 8).

### 2.2 Типографика и шрифты

- Шрифты: **Onest** (UI), **Lora** (заголовки/логотип),
  **JetBrains Mono** (время, токены, коды).
- Шкала: `display` 48/56, `h1` 32/40, `h2` 24/32, `h3` 20/28, `h4` 16/24,
  `body-lg` 16/24, `body` 14/20, `body-sm` 13/18, `caption` 12/16, `overline` 11/16
  (uppercase, letter-spacing 0.08em), `mono` 13/18.
- **Шрифты self-hosted** (раздел 10): файлы лежат в `web/public/fonts/`,
  подключение — `web/public/fonts/fonts.css` (без обращения к внешним CDN в
  рантайме). Подключение и inline-скрипт выбора темы — в `web/index.html`
  (защита от «мигания» при загрузке).
- **Кириллица поддерживается всеми тремя шрифтами** (Onest, Lora, JetBrains Mono)
  — кириллические подмножества включены в self-host набор.

### 2.3 Прочее

- Радиусы: `sm` 6, `md` 10, `lg` 14, `xl` 20.
- Тени: `card`, `card-hover`, `modal`, `dropdown`, `focus` (ring акцента).
- Ускорения: `ease-out-expo`, `ease-spring`.
- Анимации (keyframes): `fade-in`, `fade-in-up`, `scale-in`, `slide-in-right`,
  `shimmer` (скелетоны), `weave` (логотип), `spin-slow`.

## 6. Реализовано: календарь, анимации, доступность

### 6.1 Стилизация календаря (FullCalendar)
`web/src/styles/calendar.css`: панель инструментов, кнопки, заголовки дней,
номера дней, слоты времени, «сегодня», состояние перетаскивания (`fc-event-dragging`),
продсветка цели (`fc-highlight`). Тексты и цвета — из токенов темы.

### 6.2 Анимации
- Появление списков/карточек — `fade-in-up` со сдвигом по индексу (пространства,
  источники, история).
- Модалки/дропдауны/тосты — `scale-in` / `slide-in-right`.
- Логотип — `weave`; скелетоны — `shimmer`.
- Пульсация конфликта — CSS-класс `conflict-indicator`; **подключён** к
  индикатору ошибки синхронизации в шапке (раздел 10).

### 6.3 Доступность (a11y)
- Фокус-ринг акцента на интерактивных элементах (`focus-visible`).
- `aria-label`/`title` у всех иконочных кнопок (навигация, тема, уведомления,
  профиль, сворачивание сайдбара, меню).
- Таблицы: `scope="col"`, скрытая подпись для колонки действий.
- Индикатор подключения — `role="status"`, `aria-live="polite"`.
- Ошибки форм — `role="alert"`.
- Активные/неактивные состояния навигации — через `aria-current` (NavLink).
- Контраст текста проверяется автоматическим аудитом WCAG (раздел 10); в обеих
  темах устранены критические значения ниже 3:1.
- Уважение `prefers-reduced-motion: reduce` — глобально отключает анимации/переходы.

## 7. Как проверить

1. Запустить инфраструктуру: `docker compose -f infra/docker-compose.yml up -d`.
2. Backend: `node dist/main.js` (папка `backend`) → `http://localhost:3000/health`.
3. Web: `pnpm run dev` (папка `web`) → `http://localhost:5173`.
4. Войти: `demo@pletenie.local` / `demo12345`.
5. Проверить: переключение темы (шапка/профиль), сворачивание сайдбара,
   адаптив (сужение окна < 1024px → drawer), календарь (перетаскивание события),
   формы, пустые состояния.

## 10. Ответ на замечания ревью заказчика

По итогам ревью дизайна закрыт блок **P0** и подключён индикатор ошибки
синхронизации. Все изменения зафиксированы отдельными коммитами.

### 10.1 P0 — шрифты, светлая тема, регрессия

| Замечание | Что сделано | Коммит |
|-----------|-------------|--------|
| Шрифты грузятся из внешних CDN (Fontshare/Google), ненадёжно и оффлайн-небезопасно | Шрифты **self-hosted** в `web/public/fonts/` + `fonts.css`, без CDN. По итогам ревью семья заменена на **Onest (UI) + Lora (заголовки)** с кириллицей (JetBrains Mono — моно) | `94dd6f5`, далее миграция Onest/Lora |
| Светлая тема не прогонялась целиком | Прогон всех экранов в светлой теме: аудит контраста, visual-регрессия и e2e | `48a771d`, `2ff22f8` |
| Нет автоматической проверки внешнего вида | **Visual regression** Playwright: 16 эталонов (7 экранов × dark/light + вход), детерминированные (фиксированное время/тема) | `2ff22f8` |
| Контраст текста не проверялся | **Аудит контраста WCAG** (`theme-audit.spec.ts`): собственный расчёт соотношения с учётом альфа-композитинга; в обеих темах устранены критические значения < 3:1 | `2ff22f8`, `48a771d` |
| — | Исправлен баг слияния классов (`cn`/tailwind-merge): кастомные размеры шрифтов ошибочно «съедали» цвет текста | `4e183fc` |

### 10.2 Что именно исправлено по контрасту

- Введён токен `on-accent` (белый) для кнопок и бейджей на акцентном фоне —
  ранее текст был цветом `body` (в светлой теме 2.86:1).
- `text-muted` затемнён в обеих темах для читаемости служебных подписей.
- Активная кнопка календаря и заголовок «сегодня» получили достаточный контраст.
- Аватар: фон формируется затемнением цвета по имени (убрана зависимость от
  `color-mix()`, которая в inline-стиле не применялась).
- Время события в календаре переведено на `text-secondary` (на подложке события
  было 2.5:1).

Остаются слегка ниже AA (3.4–4.4) второстепенные приглушённые подписи — осознанный
компромисс ≥ 3:1, зафиксирован в аудите.

### 10.3 Индикатор ошибки синхронизации (`conflict-indicator`)

CSS-класс `conflict-indicator` (пульсация), ранее не использовавшийся, подключён
к индикатору ошибки синхронизации:

- Состояние синхронизации хранится в `web/src/store/sync.ts` (`idle` / `error`).
- `QueryCache`/`MutationCache` TanStack Query помечают ошибку при **сетевой**
  недоступности API (`web/src/lib/errors.ts`).
- Компонент `SyncIndicator` (`web/src/components/SyncIndicator.tsx`) показывается в
  шапке рядом с индикатором подключения, с `role="status"` и понятной подписью.
- Покрытие: unit-тест компонента + e2e-сценарий «API недоступен → индикатор
  появляется».

### 10.4 Проверки после изменений

- Аудит контраста: критических нарушений (< 3:1) — **0**.
- Visual-регрессия: **16/16**.
- Полный e2e (Playwright): **39/39** (для детерминизма `workers: 1` — тесты,
  создающие данные, изолированы).
- TypeScript — без ошибок, oxlint — 0 замечаний, Vitest — 3/3.
