# Отчёт по дизайн-системе Web (для заказчика)

Проект: **Плетение** — календарь-планировщик.
Область отчёта: приведение веб-приложения к дизайн-спецификации дизайнера
(«полная дизайн-система»), поэтапно.
Дата: 17.10.2026. Статус: **реализовано полностью** (5 фаз, см. раздел 9).

Связанные документы: `docs/design.md` (спецификация токенов/компонентов),
`docs/progress.md` (отчёт о ходе работ по этапам).

---

## 1. Краткое резюме

Дизайн-спецификация дизайнера переведена в рабочую дизайн-систему веб-клиента:
токены оформления, типографика и шрифты, набор UI-компонентов, каркас
(шапка/сайдбар), все экраны, анимации и базовая доступность.

Реализация разбита на 5 фаз (каждая — отдельный коммит):

| Фаза | Содержание | Коммит |
|------|------------|--------|
| 1 | Токены, темы, шрифты, тёмная тема по умолчанию | `22ab028` |
| 2 | UI-примитивы (кнопки, поля, карточки, модалки, тосты и т.д.) | `f40068d` |
| 3 | Каркас: шапка 64px, сворачиваемый сайдбар 280/64, поиск | `7ee01c0` |
| 4 | Переоформление всех экранов | `c5b96e7` |
| 5 | Анимации, стаггер списков, доступность (a11y), reduced-motion | `77a8b3a` |

Проверки каждой фазы: TypeScript — без ошибок, oxlint — 0 замечаний,
Vitest 1/1, production-сборка Vite — успешно.

## 2. Реализовано: токены оформления

Тёмная тема — **основная** (по умолчанию), светлая — включается классом `.light`
на `<html>`. Значения заданы в `web/src/styles/themes.css`, проброшены в Tailwind 4
через `@theme inline` (`web/src/index.css`).

### 2.1 Цвета

| Группа | Токены | Тёмная (основная) | Светлая |
|--------|--------|-------------------|---------|
| Фоны | `bg` / `bg-surface` / `bg-elevated` | `#1A1A1E` / `#25252B` / `#2E2E35` | `#FAF8F5` / `#FFFFFF` / `#F0EDE8` |
| Границы | `border` / `border-subtle` | `#3A3A42` / `#2E2E35` | `#E0DCD5` / `#EDEAE4` |
| Акцент | `accent` (+hover/active/muted) | `#5B5FEF` | `#4A4EE0` |
| Amber (токены доступа) | `amber` (+hover/active/muted) | `#F0A030` | `#D98A1F` |
| Успех | `success` (+muted) | `#34C77B` | `#2BA865` |
| Опасность/конфликт | `danger` (+hover/active/muted) | `#E05C4A` | `#C94A38` |
| Текст | `text-primary` / `text-secondary` / `text-muted` / `text-inverse` | `#F5F3EF` / `#A8A29E` / `#6B6B72` / `#1A1A1E` | `#1A1A1E` / `#6B6660` / `#A8A29E` / `#FAF8F5` |

Прозрачные «muted»-варианты акцентов реализованы как `rgba(...)` (подложки бейджей,
чипов, конфликтов).

> Примечание о совместимости: сохранены устаревшие имена токенов
> (`surface`→`bg-surface`, `text`→`text-primary`, `muted`→`text-secondary`,
> `conflict`→`danger`, `accent-2`→`amber`), чтобы не переписывать всю разметку
> разом. Это технический компромисс (см. раздел 8).

### 2.2 Типографика и шрифты

- Шрифты: **Satoshi** (UI, Fontshare), **Instrument Serif** (заголовки/логотип,
  Google Fonts), **JetBrains Mono** (время, токены, коды).
- Шкала: `display` 48/56, `h1` 32/40, `h2` 24/32, `h3` 20/28, `h4` 16/24,
  `body-lg` 16/24, `body` 14/20, `body-sm` 13/18, `caption` 12/16, `overline` 11/16
  (uppercase, letter-spacing 0.08em), `mono` 13/18.
- Подключение шрифтов и inline-скрипт выбора темы — в `web/index.html`
  (защита от «мигания» при загрузке).

### 2.3 Прочее

- Радиусы: `sm` 6, `md` 10, `lg` 14, `xl` 20.
- Тени: `card`, `card-hover`, `modal`, `dropdown`, `focus` (ring акцента).
- Ускорения: `ease-out-expo`, `ease-spring`.
- Анимации (keyframes): `fade-in`, `fade-in-up`, `scale-in`, `slide-in-right`,
  `shimmer` (скелетоны), `weave` (логотип), `spin-slow`.

- **Шапка 64px**: логотип (анимированный) + название, поиск разделов,

- Адаптив по брейкпоинтам sm 640 / md 768 / lg 1024 / xl 1280 / 2xl 1536.

## 6. Реализовано: календарь, анимации, доступность

### 6.1 Стилизация календаря (FullCalendar)
`web/src/styles/calendar.css`: панель инструментов, кнопки, заголовки дней,
номера дней, слоты времени, «сегодня», состояние перетаскивания (`fc-event-dragging`),
продсветка цели (`fc-highlight`). Тексты и цвета — из токенов темы.

### 6.2 Анимации
- Появление списков/карточек — `fade-in-up` со сдвигом по индексу (пространства,
  источники, история).
- Модалки/дропдауны/тосты — `scale-in` / `slide-in-right`.
- Логотип — `weave`; скелетоны — `shimmer`.
- Пульсация конфликта — CSS-класс `conflict-indicator` (см. раздел 8, к чему относится).

### 6.3 Доступность (a11y)
- Фокус-ринг акцента на интерактивных элементах (`focus-visible`).
- `aria-label`/`title` у всех иконочных кнопок (навигация, тема, уведомления,
  профиль, сворачивание сайдбара, меню).
- Таблицы: `scope="col"`, скрытая подпись для колонки действий.
- Индикатор подключения — `role="status"`, `aria-live="polite"`.
- Ошибки форм — `role="alert"`.
- Активные/неактивные состояния навигации — через `aria-current` (NavLink).
- Уважение `prefers-reduced-motion: reduce` — глобально отключает анимации/переходы.

## 7. Как проверить

1. Запустить инфраструктуру: `docker compose -f infra/docker-compose.yml up -d`.
2. Backend: `node dist/main.js` (папка `backend`) → `http://localhost:3000/health`.
3. Web: `pnpm run dev` (папка `web`) → `http://localhost:5173`.
4. Войти: `demo@pletenie.local` / `demo12345`.
5. Проверить: переключение темы (шапка/профиль), сворачивание сайдбара,
   адаптив (сужение окна < 1024px → drawer), календарь (перетаскивание события),
   формы, пустые состояния.

## 8. Что НЕ реализовано / ограничения

| Пункт | Статус | Пояснение |
|-------|--------|-----------|
| Макеты и иллюстративный логотип в Figma | ⛔ не делалось | Figma недоступна в текущем окружении; логотип — программная отрисовка |
| Реальное определение конфликтов (пульсация) | ⏸ отложено | CSS-класс `conflict-indicator` готов; сами конфликты — часть синхронизации внешних календарей (Этап 6) |
| Переходы между экранами (page transitions) | ⚠ частично | Есть базовые анимации появления; полноценных переходов между роутами нет |
| Паритет дизайн-системы на Mobile | ⚠ частично | Mobile использует собственную Material-тему; шрифты Satoshi/Instrument Serif и часть новых компонентов на mobile не переносились |
| Светлая тема под нагрузкой | ⚠ не тестировалось | Светлая тема поддержана, но прогон всех экранов в ней отдельно не проводился |
| Устаревшие имена токенов | ⚠ техдолг | Оставлены алиасы (`surface`/`text`/`muted`/`conflict`/`accent-2`) для совместимости |
| Конфиг Tailwind 3 из спецификации | ➖ отклонено | Проект на Tailwind 4 (CSS-first); отдельный `tailwind.config.js` не нужен |
| Шрифты | ⚠ внешний CDN | Грузятся с Fontshare/Google Fonts; оффлайн — системные fallback |
| Visual-regression / скриншот-тесты | ⛔ нет | Проверка — ручная + существующие e2e (Playwright, функциональные) |
