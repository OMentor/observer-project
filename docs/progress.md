### Проектные решения (согласованы с заказчиком)

- Название продукта — **Плетение**.
- Повторяющиеся события (RRULE), часовые пояса (UTC + IANA), приватные источники —
  заложены в модель сразу.
- Версии — актуальные стабильные; зафиксированы: **NestJS 11** (CommonJS; Nest 12
  в этом окружении ESM-only и несовместим с Node 22 + Jest), **Prisma 6**,
  **React 19 / Vite 8**.
- **Docker установлен** (Docker Desktop 4.95); инфраструктура поднята:
  PostgreSQL 16, Redis 7, MailHog. Postgres доступен на хосте как
  `localhost:5433` — порт 5432 на машине занят нативным PostgreSQL 16,
  поэтому Docker-порт переназначен на 5433.
- Внешние API (DeepSeek/Google/Microsoft) — моки до отдельного подключения.

### Известные ограничения

- Миграция `init` применена и seed выполнен: пользователь
  `demo@pletenie.local`, пространство «Личное», источник «Мой календарь».
- MinIO отключён из профиля по умолчанию: официальный образ `minio/minio`
  больше не доступен публично; включим `--profile storage`, когда понадобятся
  вложения.
- Для сборки mobile под Windows-таргет с плагинами нужен Developer Mode
  (для эмулятора Android/iOS не требуется).

## Этап 1 — Ядро ⏳

### Backend — готово ✅

- **Auth**: `POST /auth/register`, `/login`, `/refresh`, `/logout`. Пароли — bcrypt
  (10 раундов), access-токен 15 мин, refresh 30 дней с ротацией и хранением в Redis
  (отзыв при logout).
- **Guards**: глобальный `JwtAuthGuard` (декоратор `@Public()` для открытых
  маршрутов), `RolesGuard` (декоратор `@Roles()`).
- **Spaces**: CRUD, мягкое удаление, создание с участником-владельцем (FULL),
  проверка членства (`ensureMember` / `ensureOwner`).
- **Sources**: CRUD, привязка к пространству, приватность (SHARED/PRIVATE),
  фильтрация приватных источников для не-FULL участников.
- **Events**: CRUD, привязка к источнику, фильтр по периоду (`from`/`to`),
  автоматическая запись в `event_history` (CREATED/UPDATED/DELETED) с old/new данными.
- **Валидация**: Zod-схемы через `ZodValidationPipe`.
- **Swagger**: `/docs`, теги по модулям, Bearer.
- **Тесты**: 21 unit-тест (Auth, Spaces, Sources, Events), все зелёные.
- **Smoke-тест**: регистрация → вход → пространство → источник → событие →
  история (CREATED, затем UPDATED) → список; запрос без токена → 401; проверена
  корректная запись UTF-8.

### Web (FE) — готово ✅

- **Авторизация**: страницы входа и регистрации, доступ-токен + refresh с
  автоматическим обновлением (интерцептор в `lib/api.ts`), состояние сессии в
  Zustand с сохранением; защищённые маршруты (`ProtectedRoute`).
- **Пространства**: список пространств с созданием, страница пространства с
  источниками (создание, цвет, приватность) и событиями.
- **Календарь**: FullCalendar (месяц/неделя/день), сводка событий по всем
  источникам, создание по клику на дату, редактирование по клику на событие,
  модалка события (название, источник, дата/время, весь день, место, описание),
  легенда источников, русская локаль.
- **Каркас**: сайдбар с разделами (Токены, Участники, История, Настройки,
  Профиль — плейсхолдеры на следующий этап), меню пользователя и выход.
- **UI-кит**: Button, Input, Label, Dialog (Radix), дизайн-токены из ТЗ.
- **Проверка**: Vite build ✅, oxlint 0 замечаний ✅, Vitest 1/1 ✅,
  dev-сервер `http://localhost:5173` → 200 ✅.
