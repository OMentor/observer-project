# Визуальная проверка Mobile (1 день)

Дата: 18.10.2026. Устройство: **Android-эмулятор Pixel_9 (API 36, x86_64)**, backend
NestJS на хосту (`localhost:3000`, `adb reverse tcp:3000 tcp:3000`), БД PostgreSQL
(`infra/docker-compose`). Учётка `demo@pletenie.local` / `demo12345`.

Проверка проводилась без просмотра пикселей: структура экранов — через
`uiautomator dump` (тексты, bounds, отступы), ошибки/краши — через logcat,
поведение — через adb-ввод (тапы, свайпы, `svc wifi`, `settings font_scale`).
Пиксельные проверки (оттенки, наложения «глазами») закрыты golden-тестами на хосте.

## Найденные и исправленные проблемы

1. **Блокер: Android блокировал HTTP к backend** — в `AndroidManifest.xml` не было
   `android:usesCleartextTraffic="true"` (targetSdk 9+ запрещает cleartext). Симптом:
   бесконечный спиннер на календаре/пространствах, «Офлайн» в realtime-индикаторе.
   Исправлено + заодно лейбл приложения `pletenie_mobile` → «Плетение».
2. **a11y: FAB «Создать событие» без семантики** — добавлен `tooltip` (даёт
   accessibility-лейбл для TalkBack и подсказку по long-press).

## Найденные проблемы (не исправлены, в бэклог)

1. **Realtime-сокет не обновляет access token.** Access token живёт 15 минут
   (`JWT_EXPIRES_IN=15m`), сокет авторизуется токеном при `connect()`; после истечения
   токена (`socket.io` reconnect) сервер отвечает отказом, индикатор навсегда показывает
   «Офлайн» до перелогина. Нужен reconnect с токеном из `sessionManager` на событие
   «сессия обновлена» (или auth через refresh-флоу на уровне сокета).
2. **`POST /demo/seed` не сеет повторно** — проверка «has-events» считает события в
   soft-deleted пространствах (`deleted_at` не фильтруется), поэтому демо-данные нельзя
   пересоздать для cleanup-нутого аккаунта. Нужен фильтр `space.deleted_at: null`.
3. **Экран логина: после показа клавиатуры лэйаут «прыгает»** (логотип смещается с
   y=674 в y=149) — ожидаемое поведение `resizeToAvoidBottomInset`, но можно проверить
   на реальном устройстве с разными IME.

## Ограничения этой проверки

- **Пиксельный осмотр не выполнялся** (модель без зрения): оттенки, тени, точное
  совпадение с web-макетом закрыты golden-тестами на хосте, но не «глазами».
- **FPS/джиттер** — замерить только на реальном устройстве (Impeller не отдаёт кадры
  в `dumpsys gfxinfo`).
- **iOS** — не проверяется на Windows (сборка требует macOS/Xcode).
- **TalkBack-озвучка** — структура a11y-дерева есть, звук/фокус требуют ручного прогона.
- Для прогона потребовалось: запустить Docker Desktop (PostgreSQL/Redis были остановлены
  вместе с ним — backend отдавал 500 на `/auth/login`), `adb reverse tcp:3000 tcp:3000`,
  сборка с `--dart-define=API_URL=http://10.0.2.2:3000` не понадобилась благодаря reverse.
