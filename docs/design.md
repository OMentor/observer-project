# Дизайн-система «Плетение»

Источник истины по токенам, типографике и компонентам для Web и Mobile.
Обновлено под дизайн-спецификацию дизайнера: **тёмная тема — основная**, новые
шрифты, расширенный набор компонентов, анимации.

Макеты в Figma (иллюстративный логотип, полные макеты экранов) — отдельный артефакт;
в текущем окружении Figma недоступна, поэтому значения зафиксированы здесь и
синхронизированы с реализацией (`web/src/index.css`, `web/src/styles/*`,
`mobile/lib/core/theme/app_theme.dart`).

Связанные документы: `docs/report-ui.md` (отчёт для заказчика по веб-дизайн-системе),
`docs/progress.md` (отчёт о ходе работ по этапам).

---

## 1. Бренд

- Название: **Плетение** (кодирует «сплетение» расписаний из разных источников).
- Идея: переплетение нитей-календарей в единое полотно.
- Логотип: **решётка из переплетённых нитей** — два вертикальных и два горизонтальных
  штриха, которые на каждом пересечении чередуют «поверх / под». Реализован программно
  (`web/src/components/ui/logo.tsx`, константа `LOGO_STRANDS`) с анимацией `weave`:
  нити вплетаются по очереди через `stroke-dashoffset` на нормированном
  `pathLength="100"`. При `prefers-reduced-motion: reduce` решётка показывается
  целиком, без вплетения. Иллюстративный макет — внешний артефакт (Figma).
- Знак экспортируется в `web/public/`: `favicon.svg`, `icon.svg` и PNG-иконки
  `web/public/icons/` (регенерируются скриптом `web/scripts/generate-icons.mjs`).

## 4. Пространство, сетка, радиусы, тени, движение

- Базовый шаг: **4px** (Tailwind `1` = 4px).
- Отступы: карточки 16px, панели 24px; контент-контейнер `max-w-[1440px]`.
- Радиусы: `sm` 6, `md` 10, `lg` 14, `xl` 20.
- Тени: `card`, `card-hover`, `modal`, `dropdown`, `focus` (ring акцента).
- Ускорения: `ease-out-expo` `cubic-bezier(0.4,0,0.2,1)`,
  `ease-spring` `cubic-bezier(0.34,1.56,0.64,1)`.
- Анимации: `fade-in`, `fade-in-up`, `scale-in`, `slide-in-right`, `shimmer`,
  `weave`, `spin-slow`. Поддержан `prefers-reduced-motion`.

## 6. Состояния и паттерны

- Пустое состояние — `EmptyState` (иконка, заголовок, описание, действие).
- Загрузка — скелетоны (`shimmer`) или спиннер в кнопке (`loading`).
- Ошибка — `danger`-цвет рядом с формой, `role="alert"`.
- Уведомления — тосты (Web, top-right) / snackbar (Mobile).
- Приватность источника — метка «Общий»/«Личный».

---

## 7. Сводный календарь (Web)

FullCalendar (месяц/неделя/день), стилизация — `web/src/styles/calendar.css`:
панель инструментов, кнопки, заголовки/номера дней, слоты времени, «сегодня».
Перетаскивание и resize (`interaction`), обратная связь при drag
(`fc-event-dragging`), подсветка цели (`fc-highlight`). События рисуются с цветной
левой границей цвета источника; маскированное «Занято» — `#8D99AE`, приглушено.

Конфликты: CSS-класс `.conflict-indicator` (пульсация) подготовлен; фактическое
определение конфликтов — часть синхронизации внешних календарей (Этап 6).

## 8. Доступность

- Фокус-ринг акцента на интерактиве (`focus-visible`).
- `aria-label`/`title` у иконочных кнопок; `aria-current` в навигации.
- Таблицы: `scope="col"`, скрытые подписи колонок действий.
- Индикатор подключения — `role="status"`, `aria-live="polite"`.
- Ошибки — `role="alert"`.
- Контраст ≥ 4.5:1; интерактив ≥ 24×24px; уважение `prefers-reduced-motion`.

## 10. Доступ (пресеты, токены, участники, история)

Модель доступа: участник пространства имеет один **пресет** (роль доступа),
владелец всегда FULL.

| Пресет | Код   | Видит события          | Меняет события            | Источники/токены | История |
|--------|-------|------------------------|---------------------------|------------------|---------|
| Полный | FULL  | полностью              | любые                     | создаёт/удаляет  | доступна|
| Свой   | OWN   | свои полностью, чужие — «Занято» | только свои       | —                | своих   |
| Занят  | BUSY  | только «Занято»        | нет                       | —                | нет     |
| Чтение | READ  | полностью              | нет                       | —                | доступна|

Маскированное событие (BUSY, а также чужие при OWN): заголовок «Занято»,
описание/место пусты, цвет `muted` (`#8D99AE`).

Компоненты доступа:

- **Переключатель пространства** (`SpacePicker`) — на страницах токенов/участников/
  настроек; на Mobile — через действия в шапке.
- **Токены** — список (Пресет, Создал, Создан, Действует до, Статус); создание
  одиночное и пакетом (до 100); единоразовый показ с копированием и ссылкой
  `/activate/<token>`; отзыв.
- **Участники** — список, смена пресета, исключение (мягкий отзыв); владелец
  защищён.
- **Активация** — `/activate/<token>`.
- **История** — журнал (Создано/Изменено/Удалено, автор, дата, `старый → новый`).

Статусы токена: **Активен** (`accent`), **Использован**/**Истёк** (`muted`),
**Отозван** (`danger`).

## 11. Real-time (Этап 4)

- **Индикатор подключения** (Web `ConnectionIndicator`, Mobile `RealtimeIndicator`):
  «Подключение…» (amber, пульсация) / «Онлайн» (success) / «Офлайн» (muted).
- **Уведомления**: Web — тосты (`Toaster`, top-right, автоскрытие 5 c, тона
  info/success/warning/danger); Mobile — snackbar.
- Уведомления не показываются для собственных действий (сравнение `actor_id`).
- Обновление данных — фоном (инвалидация запросов), без «прыжков» интерфейса.

## 12. Совместимость имён токенов

Сохранены устаревшие алиасы (для постепенного перехода разметки):
`surface`→`bg-surface`, `text`→`text-primary`, `muted`→`text-secondary`,
`conflict`→`danger`, `accent-2`→`amber`. Это технический долг.
