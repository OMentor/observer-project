# ИИ (DeepSeek)

Реализуется на этапе 7. Внешние вызовы на этапах до 7 — моки/заглушки.

## Конфигурация

```
DEEPSEEK_API_KEY=sk-xxxxx
DEEPSEEK_BASE_URL=https://api.deepseek.com
```

## Возможности

| Функция | Эндпоинт | Описание |
|---------|----------|----------|
| Парсинг языка | `POST /ai/parse` | «Встреча завтра в 15:00» → событие |
| Умные фильтры | `GET /ai/filters` | Семантический поиск по событиям |
| Конфликты | `POST /ai/conflict-suggest` | Вариант разрешения конфликта синхронизации |
| Чат в событиях | WebSocket + `/events/:id/...` | Обсуждение внутри события |
| Шаблоны | CRUD шаблонов | Быстрое создание повторяемых событий |

## Ограничения

- Внешние интеграции могут быть недоступны из РФ — используем тестовые аккаунты
  или моки.
- Ключи не коммитятся и не передаются третьим лицам.
